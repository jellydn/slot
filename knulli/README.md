# Knulli launcher

This folder is a Knulli Port launcher for the TrimUI Smart Pro (A133P).
The project goal is Slot on TrimUI Stock OS (Tina Linux). See the root
[README](../README.md).

## Install

1. Download [slot-knulli-tsp-0.1.0.zip](https://github.com/jellydn/slot-tsp/releases/download/knulli-tsp-0.1.0/slot-knulli-tsp-0.1.0.zip)
   from [knulli-tsp-0.1.0](https://github.com/jellydn/slot-tsp/releases/tag/knulli-tsp-0.1.0).
2. Unzip it into `/userdata/roms/ports/Slot`, so that `Slot.sh` sits at
   `/userdata/roms/ports/Slot/Slot.sh`.
3. Refresh Ports in EmulationStation.
4. Launch Slot from the Ports section.

## ROMs

Put unzipped ROMs (no zip files) in:

- `Games/GB` — Game Boy
- `Games/GBC` — Game Boy Color
- `Games/GBA` — Game Boy Advance

## Notes

Experimental. The 16:9 shelf fills the panel; games stay 3:2 and are
letterboxed.
